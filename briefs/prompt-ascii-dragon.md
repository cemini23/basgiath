# Task: draw a better ASCII dragon

Historical. The art is already in `docs/ascii-dragon.txt`. Do not overwrite it.

Overwrite the file `docs/ascii-dragon.txt` with a single, large ASCII art dragon. Nothing else in that file — no code fences, no caption, no title, no explanation.

## Requirements

- At least 26 lines tall and 64 columns wide. Larger is welcome.
- Printable ASCII only. No Unicode, no emoji, no box-drawing characters.
- It must read clearly as a dragon: a horned head, a jaw, spread bat-like wings, a body, legs or claws, and a long tail.
- Add shading. Vary the density of characters (` . , - ~ : ; = ! * # $ @` plus `/ \ _ | ( ) [ ] { } + < >`) so the form has depth and a light source.
- Align every line so the shape holds when viewed in a monospace font. Watch the columns — do not let the silhouette drift.
- No text above, below, or beside the art.

## Output

Write the art to `docs/ascii-dragon.txt` using the file write tool. Then print the finished art in your reply so it can be checked.

Do not modify any other file.
