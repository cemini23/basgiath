### Root cause
The world header and the map generator were written by different hands against different assumptions. `build_world.py` writes a generic flat-world header (creative game type, limited origin at y=64, required texture pack, multiplayer on) while `build_map.py` assumes an adventure-mode, single-player, no-RP-required world built at y=-2. The two never cross-check, so the header silently contradicts the design. The Signet gate is a second, independent root cause: the bond trigger is a hard-coded box in `zone-valley.py` that the keeper path and the dell rim fall outside, and nothing in `main.js` or the live layer tells the player they missed it.

### Confidence
high — every finding is a literal string in `build_world.py`, `build_map.py`, `zone-valley.py`, or `main.js`, cross-referenced against `README.md`/`DESIGN.md`.

### Unique angle
The `LimitedWorldOriginY: 64` header. Every prior audit read the experiments block and stopped; none checked the limited-world anchor, which sits 64 blocks above a college built at y=-2..33. On a phone with a limited world, that origin defines the border center — the build is below it, and the spawn point at y=0 is 64 blocks from the anchor. This is the same class of defect as the beta-API flag: a single header field that changes gameplay in a way the design never intended, invisible to every checker because `test_release.py` only asserts `Generator`, `commandsEnabled`, `sendcommandfeedback`, and `LevelName`.
