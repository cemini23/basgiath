# Build checklist

Do these in order. Times are for one person, first time.

## 0. Setup (about 30 min)
- [ ] Install Minecraft Bedrock (Windows 11 or a device).
- [ ] Enable the in-game **Bedrock Editor**.
- [ ] Copy the packs into the dev folder:
      `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\development_behavior_packs\`
      and `...\development_resource_packs\`
- [ ] Create a flat world. Enable both packs and the **Beta APIs** toggle.
- [ ] Test the form: place a lodestone, tap it. Answer three questions. Confirm a signet title appears.
      If nothing happens, run `/scriptevent dragon_rider:signet`.

## 1. The chasm (2-3 h)
- [ ] Carve a chasm about 40 deep and 60 wide.
- [ ] Line the walls with deepslate and stone. Add fog below.
- [ ] Lock the weather to rain and thunder.

## 2. The Parapet (2-4 h)
- [ ] Build a one-wide stone path across the chasm.
- [ ] Leave a two-block gap at the centre.
- [ ] Add a checkpoint (a pressure plate and a command block that sets the spawn) at each end.
- [ ] Add wind: a repeating command block that pushes the player sideways while they are on the span.

## 3. The Quad (3-5 h)
- [ ] Flatten an area about 80 by 80.
- [ ] Build bleachers, banners, and a bell tower for silhouette.
- [ ] Place the **Bonding Stone** — a lodestone — at the centre, on a raised dais.
- [ ] Add a sign next to it: "Touch the stone. Let a signet choose you."

## 4. Polish (2-3 h)
- [ ] Add lanterns and torches for the night shots.
- [ ] Add a short spawn message: "Welcome, candidate. Cross the Parapet."
- [ ] Playtest the Parapet three times. Tune the wind so it is hard but fair.

## 5. Export (30 min)
- [ ] Test on a tablet or phone, not just desktop.
- [ ] Export the world as `.mcworld`.
- [ ] Export the packs as `.mcaddon`.

## 6. Capture the clip (1 h)
- [ ] Record the Parapet crossing in the rain, at night.
- [ ] Record the signet result card.
- [ ] Cut two clips, 15-30 seconds each. Vertical.

Total first pass: roughly **12-18 hours**. Finish the Parapet first. It is the clip.
